## 🔑 Ключевые элементы системы:

### 1. GCLID (Google Click Identifier)
```
Что это: Уникальный ID каждого клика по рекламе
Где хранится: localStorage (90 дней) + Google Таблица
Зачем нужен: Связывает клиента с конкретным кликом по рекламе
```

### 2. Enhanced Conversions
```
Что это: Передача хешированных данных клиента (email, телефон)
Зачем: Google может точно match клиента даже без cookies
Результат: +5-20% к точности отслеживания
```

### 3. Transaction ID
```
Что это: Уникальный ID конверсии (lead-1234567890-Cj0KCQ...)
Зачем: Связывает запись в таблице с конверсией в Google Ads
Использование: Для offline conversions и анализа
```

### 4. Status (квалификация лидов)
```
new_lead: Только пришел, еще не обработан
qualified: Качественный лид, готов покупать
disqualified: Некачественный, не целевой клиент
```

---

## 📈 Как это улучшает результаты:

### Без системы:
```
100 кликов → 10 лидов → ? качественных → Google не знает что работает
```

### С системой:
```
100 кликов → 10 лидов → 7 qualified → Google ВИДИТ что работает
                      → 3 disqualified → Google УЧИТСЯ избегать их

Результат: Следующие 100 кликов → 15 лидов → 12 qualified
```

---

## 💡 Почему это мощная система:

1. **Полная прозрачность**: Вы видите весь путь от клика до qualified лида
2. **Обучение алгоритма**: Google Ads понимает что такое "хороший клиент"
3. **Offline conversions**: Можете отправлять события после звонка клиенту
4. **Enhanced match**: Работает даже если cookies заблокированы
5. **90-дневное окно**: Учитываются даже долгие циклы принятия решения
