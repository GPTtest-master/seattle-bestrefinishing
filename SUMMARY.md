## 🎯 Как это работает

```
1. Клик по Google Ads рекламе
   ↓
2. GCLID автоматически ловится и сохраняется (90 дней)
   ↓
3. Клиент заполняет форму
   ↓
4. Две вещи происходят одновременно:
   
   A) Google Ads Enhanced Conversion:
      • Хешированный email
      • Хешированный телефон
      • ZIP код
      • Transaction ID
      • Value в USD
   
   B) Google Sheets запись:
      • Все данные клиента
      • GCLID
      • Transaction ID
      • Status: new_lead
   ↓
5. Вы квалифицируете лида:
   • qualified = хороший клиент
   • disqualified = не целевой
   ↓
6. Google Ads обучается на qualified лидах
   ↓
7. Результат: больше качественных лидов по меньшей цене
```

## 💡 Ключевые преимущества системы

### 1. Enhanced Conversions
**Проблема:** Cookies блокируются, конверсии теряются  
**Решение:** Хешированные email/телефон для точного match  
**Результат:** +5-20% к точности отслеживания

### 2. GCLID в таблице
**Проблема:** Не понятно какой клик привел клиента  
**Решение:** GCLID сохраняется с каждым лидом  
**Результат:** Полная прозрачность attribution

### 3. Квалификация лидов
**Проблема:** Google оптимизирует на ВСЕ лиды (хорошие и плохие)  
**Решение:** Вы отмечаете только qualified лиды  
**Результат:** Google оптимизирует только на качественных

### 4. Transaction ID
**Проблема:** Невозможно связать конверсию с конкретным лидом  
**Решение:** Уникальный ID для каждой конверсии  
**Результат:** Offline conversions и детальная аналитика
