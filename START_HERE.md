## ⚡ Быстрый старт (15 минут)

### Шаг 1: Обновите Google Таблицу
Добавьте 3 новые колонки:

```
H: gclid
I: transaction_id  
J: status
```

### Шаг 2: Обновите Google Apps Script
```
1. Откройте вашу Google Таблицу
2. Расширения → Apps Script
3. Скопируйте код из google-apps-script.js
4. Вставьте вместо старого
5. Сохраните (Ctrl+S)
```

### Шаг 3: Протестируйте
```
1. Откройте: ваш-сайт.com/?gclid=test123
2. Заполните форму
3. Проверьте Google Таблицу
4. В колонке H должен быть: test123
```

## 📞 Техподдержка

### Если что-то не работает:

1. **GCLID не ловится**
   - Проверьте консоль браузера (F12)
   - Должно быть: "🔎 GCLID loaded"
   - Откройте с параметром ?gclid=test

2. **Данные не попадают в таблицу**
   - Проверьте Google Apps Script
   - Посмотрите "Выполнения" для ошибок
   - Убедитесь что URL скрипта правильный

3. **Enhanced Conversions не работают**
   - Google Ads → Аудитории → Источники данных
   - Должен быть статус "Настроено"
   - Проверьте консоль: "✅ Enhanced Conversion fired"
